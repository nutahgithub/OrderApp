# Step 10.1 - Frontend UI Refactor Foundation

## Muc Tieu

Refactor UI frontend de code de maintain hon, giam CSS viet tay, chuan hoa data fetching/form validation, va tao nen tang component dung chung truoc khi tiep tuc polish/release.

Scope nay chi tap trung frontend trong `apps/web`. Khong doi API contract neu khong that su can.

## Hien Trang Project

- Web app dang dung React 19, Vite 6, TypeScript, React Router 7.
- Chua co UI library, chua co TailwindCSS. Style dang nam chu yeu trong `src/styles/global.css` voi nhieu class custom nhu `panel`, `metric-card`, `order-row`, `menu-form`.
- Da co shared UI rat mong: `Button`, `Input`, `StateMessage`, `LanguageSwitcher`.
- API client dang typed va unwrap `{ data }` tot, nhung dung `fetch` thu cong. Token duoc truyen lap lai vao tung method.
- Server state dang quan ly bang `useState`/`useEffect` trong tung page. Loading/error/success union state bi lap o dashboard, branches, tables, menus, orders, customer QR.
- Realtime Socket.IO da co, nhung logic ket noi/fallback dang nam truc tiep trong page.
- Form validate hien tai chua dong nhat:
  - Login/branch/table chu yeu dua vao HTML `required`.
  - Menu co validate price bang regex rieng trong page.
  - API backend da dung Zod, nhung frontend chua co schema validation chung.
- Source frontend da co huong tach `components`, `features`, `lib`, `pages`, nhung feature logic con nam nhieu trong page component.

## Quyet Dinh Ky Thuat De Xuat

### UI Library

Khuyen nghi dung **TailwindCSS + shadcn/ui style components + Radix UI primitives**.

Ly do:

- Project la admin/customer operational tool, can UI gon, tuy bien cao, khong can bo component nang va theme opinionated nhu Ant Design.
- Tailwind hop voi mong muon viet UI nhanh, giam file CSS custom lon.
- shadcn/ui khong phai dependency UI dong kin; component copy vao source, de tuy bien, de i18n, de giu design rieng cho nha hang/cafe.
- Radix UI phu hop cho Dialog, Select, Popover, Tabs, Toast voi accessibility tot.

Khong uu tien Ant Design trong scope nay vi giao dien de bi "enterprise generic", bundle/style override lon, kho giu customer QR mobile-first theo brand rieng. MUI co chat luong tot nhung cung can theme override nhieu va style system trung lap voi Tailwind. Neu can data table nang sau nay thi co the them TanStack Table rieng, khong can chon full UI framework.

### CSS

Dung **TailwindCSS** lam styling chinh.

- Cai dat Tailwind cho `apps/web`.
- Tao design tokens trong `tailwind.config`/CSS variables: color, radius, spacing, shadow.
- Tat ca mau UI phai di qua token tap trung, khong viet hex color rai rac trong page/component.
- Giu `global.css` cho base styles va Tailwind directives, khong tiep tuc phinh to CSS page-specific.
- Chuyen dan class custom sang component variants bang `class-variance-authority` va helper `cn`.

### Theme & Mau Sac

Can them theme system de user co the chon style hien thi, dong thoi giu color palette cua project nam mot cho.

Huong trien khai:

- Tao `src/lib/theme/theme-tokens.ts` hoac `src/styles/theme.css` de khai bao CSS variables:
  - `--background`
  - `--foreground`
  - `--card`
  - `--card-foreground`
  - `--primary`
  - `--primary-foreground`
  - `--secondary`
  - `--secondary-foreground`
  - `--muted`
  - `--muted-foreground`
  - `--accent`
  - `--accent-foreground`
  - `--destructive`
  - `--destructive-foreground`
  - `--border`
  - `--input`
  - `--ring`
  - `--success`
  - `--warning`
  - `--info`
- Map Tailwind colors vao CSS variables, vi du `bg-background`, `text-foreground`, `bg-primary`, `border-border`.
- Tao `ThemeProvider` va `useTheme()` trong `src/lib/theme/ThemeContext.tsx`.
- Luu theme user chon vao `localStorage`, apply bang attribute tren root element, vi du `data-theme="fresh"`.
- Them UI control cho user chon theme trong admin shell va customer toolbar neu can.
- Toi thieu nen co cac theme:
  - `fresh`: xanh la/xanh ngoc cho nha hang/cafe, dung lam default.
  - `classic`: trung tinh, de nhin cho admin van hanh lau.
  - `high-contrast`: contrast cao hon cho moi truong ban hang sang man hinh.
- Theme phai anh huong ca admin va customer QR, nhung customer QR co the co spacing/layout rieng mobile-first.
- Status colors nhu order/table/payment khong hard-code trong page; khai bao thanh semantic token hoac mapping chung trong `lib/theme/status-colors.ts`.
- Khi them theme moi, khong sua tung component; chi them token values.

Acceptance rieng cho theme:

- User doi theme khong can reload app.
- Reload van giu theme da chon.
- Tat ca component UI chinh dung token Tailwind/CSS variables.
- Light/dark/high contrast neu them sau khong yeu cau refactor lai page.

### API & State Management

Khuyen nghi dung **TanStack Query** cho server state, giu `fetch` typed client hoac tach `httpClient` rieng. Chua can Redux.

Ly do:

- Du lieu hien tai chu yeu la server state: branches, tables, menus, orders, dashboard, QR entry.
- App can cache, refetch, invalidate sau mutation, loading/error state dong nhat. Day la dung bai cua TanStack Query.
- Redux/Redux Toolkit chi nen them neu co client state phuc tap nhu workflow editor, offline queue, permission matrix, POS cart phuc tap nhieu man hinh. Hien tai auth/i18n/cart nho co the giu bang Context/local state.
- Axios khong bat buoc. `fetch` typed hien tai da du dung. Neu chon Axios thi nen vi interceptor/cancel/progress upload, khong phai de thay the TanStack Query.

Huong trien khai:

- Tao `src/lib/api/http.ts` gom base URL, JSON parse, error normalize, auth header.
- Tach endpoint theo domain: `auth.api.ts`, `branches.api.ts`, `tables.api.ts`, `menus.api.ts`, `orders.api.ts`, `reports.api.ts`, `qr.api.ts`.
- Tao query key factory: `src/lib/query/query-keys.ts`.
- Tao hooks:
  - `useBranchesQuery`
  - `useTablesQuery(branchId)`
  - `useMenusQuery`
  - `useOrdersQuery({ branchId, status })`
  - `useOrderQuery(orderId)`
  - `useDashboardQuery(filters)`
  - mutation hooks cho create/update/confirm payment/upload.
- Mutation thanh cong invalidate dung query key lien quan thay vi goi lai `loadX` thu cong trong page.

## Common Hoa Can Lam

- `formatCurrency`, `formatDateTime`, status label/status pill mapping.
- `PageHeader`, `PageSection`, `Toolbar`, `MetricCard`, `DataState`, `ConfirmDialog`.
- `ThemeSwitcher` dung chung cho admin/customer neu can.
- `BranchSelect`, `StatusSelect`, reusable form field components.
- `useToast` hoac toast component dung chung thay cho success/error message rai rac.
- `useAuthenticatedAction` hoac auth-aware API wrapper de tranh lap logic `if (!token) logout()`.
- `useRealtimeOrderUpdates` va `useRealtimeConnectionState` de tach Socket.IO khoi page.
- Image upload/compress trong menu nen tach sang `features/menus/image-upload.ts` hoac hook rieng.

## Hooks Can Co

- Data hooks voi TanStack Query cho moi resource.
- Form hooks voi React Hook Form cho create/update forms.
- `useDebouncedValue` neu sau nay co search/filter text.
- `useDisclosure` cho dialog/modal.
- `useStableEvent`/`useCallback` chi dung cho handler truyen xuong component con hoac effect dependency phuc tap; khong toi uu hoa qua som.
- `useMemo` chi giu cho derived data co chi phi hoac can on dinh reference, vi du filtered orders, selected branch, cart totals.

## Form Validation

Khuyen nghi dung **React Hook Form + Zod + @hookform/resolvers**.

Ly do:

- Backend da dung Zod, frontend dung Zod giup cung mental model.
- React Hook Form giam re-render va code form gon hon controlled state thu cong.
- Co the chuan hoa error message/i18n theo schema va mapper.

Can tao schema frontend cho:

- Login: email hop le, password bat buoc.
- Branch: name trim, min length, max length.
- Table: branchId bat buoc, name, status enum.
- Menu: name, price numeric string/number > 0, image type/size, isActive.
- Dashboard filter: startDate/endDate hop le, startDate <= endDate, branch optional.
- Order status/payment confirmation: enum va amount hop le.
- Customer order: items khong rong, quantity > 0.

Neu co the, tai su dung logic voi API schema bang package shared sau nay, nhung trong buoc 10.1 chua can tach workspace shared de tranh mo rong scope.

## Thu Tu Trien Khai

1. Cai TailwindCSS va helper UI foundation.
2. Tao theme tokens, `ThemeProvider`, `ThemeSwitcher`, va map Tailwind color sang CSS variables.
3. Tao `cn`, button/input/select/dialog/toast/state-message variants bang Tailwind.
4. Them `QueryClientProvider` vao app providers.
5. Tach API http client va query keys, giu type hien tai trong `lib/api/types.ts`.
6. Refactor tung feature theo thu tu it rui ro:
   - dashboard
   - branches
   - tables
   - menus
   - orders
   - customer QR
7. Them React Hook Form + Zod cho form sau khi UI field components on dinh.
8. Tach realtime hooks cho orders/customer tracking.
9. Don `global.css`, chi giu base/Tailwind/theme variables va nhung style that su global.

## Acceptance Criteria

- Build/typecheck/lint pass.
- Khong con CSS page-specific phinh to trong `global.css` cho cac man da refactor.
- Cac man admin/customer van co loading/error/empty/success state.
- Create/update branch/table/menu, dashboard filter, update order status, confirm payment, QR order flow van chay.
- Mutation invalidate/refetch bang TanStack Query, khong con pattern `await loadX()` lap lai o feature da refactor.
- Form validation hien thi loi gan field, message qua i18n, khong chi dua vao HTML `required`.
- UI responsive admin/customer khong bi overlap text/button o mobile.
- Mau sac/theme duoc config tap trung, user co the doi theme va lua chon duoc luu lai.

## Ngoai Scope

- Khong doi backend API contract.
- Khong them Redux trong buoc nay.
- Khong lam lai branding/toan bo visual polish Step 11.
