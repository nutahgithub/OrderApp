# Step 10.2 - Frontend UI/UX Polish

## Muc Tieu

Nang cap giao dien admin va customer QR tu muc "chay du chuc nang" len muc san pham dep, de thao tac, scan nhanh, va phu hop van hanh nha hang/cafe.

Scope nay chi tap trung frontend trong `apps/web`. Khong doi backend API contract, khong them business feature moi, khong lam deployment/release.

## Nguyen Tac Thiet Ke

- Admin la cong cu van hanh: uu tien mat do thong tin, scan nhanh, thao tac it click, trang thai ro.
- Customer QR la mobile-first ordering: uu tien de chon mon, gio hang luon thay duoc, nut dat mon ro, anh mon an de nhin.
- Dung design token/Tailwind/theme hien co, khong hard-code mau sac rai rac trong page.
- Dung component dung chung neu pattern lap lai: `PageHeader`, `Toolbar`, `MetricCard`, `Panel`, `StatusPill`, `DataList`, `EmptyState`, `ConfirmDialog` neu can.
- Khong them landing page, khong them trang marketing.
- Khong lam UI mot mau. Palette can co primary/accent/status ro nhung van giu tinh operational.
- Tat ca layout phai responsive va khong overlap text/button tren mobile.

## Pham Vi UI Can Polish

### Admin Shell

- Cai thien sidebar/nav hierarchy trong `AdminLayout`.
- Them visual state ro cho nav active, user/tenant block, theme/language area.
- Mobile admin navigation phai gon, khong gay day noi dung qua nhieu.
- Toast thong bao order moi can de doc, co icon/status, khong che noi dung quan trong.

### Dashboard

- Nang cap metric cards: hierarchy ro, label/value/supporting text de scan.
- Filter bar gon hon, ro trang thai dang filter theo branch/date.
- Top menu va order status summary can dep hon, de nhin tren desktop/mobile.
- Loading/error/empty states thong nhat voi UI system.

### Orders

- Man orders la man van hanh chinh, can polish manh:
  - Filter bar ro hon.
  - Order list de scan theo ban, thoi gian, trang thai, tong tien.
  - Selected order state noi bat nhung khong qua choi.
  - Order detail co grouping ro: thong tin ban/chi nhanh, items, total, payment, status actions.
  - Status action buttons chiem dung khong gian hop ly, khong gay roi.
  - Payment confirm dialog can gon, de tin cay, co primary/secondary action ro.
- Realtime connection pill can de hieu nhung khong gay nhieu.

### Branches / Tables / Menus

- Chuan hoa page header, filter/form/list layout.
- Form create/edit can ro label, validation, loading state.
- List item/card/table can can bang giua density va de doc.
- Menu item co anh/placeholder dep hon, action state ro.

### Customer QR

- Mobile-first polish:
  - Header cua ban/chi nhanh dep hon, trang thai ban ro.
  - Menu list de chon mon nhanh.
  - Quantity stepper de cham tren mobile.
  - Cart summary/sticky order action neu phu hop.
  - Sau khi dat mon, tracking order status ro va de refresh.
- Anh mon an phai co khung on dinh, fallback khong lam layout giat.
- Disabled/unavailable state phai than thien va ro ly do.

## Component/Common Hoa Nen Lam

- `PageHeader` cho title, eyebrow, subtitle, actions.
- `Panel` hoac `SectionPanel` cho block noi dung co border/shadow nhat quan.
- `MetricCard` cho dashboard.
- `StatusPill` dung chung cho order/table/realtime neu hop ly.
- `Toolbar` cho filter/actions.
- `EmptyState`/`DataState` neu `StateMessage` hien tai chua du linh hoat.
- `ConfirmDialog` cho payment/status destructive action neu can.
- Icon buttons dung `lucide-react` khi phu hop.

Khong bat buoc tao tat ca component neu chi dung mot lan. Chi tach component khi no giam lap code that su.

## Viec Can Lam

1. Audit UI hien tai trong `apps/web/src/pages`, `components/layout`, `components/ui`.
2. Xac dinh component/common style can them ma khong lam phinh scope.
3. Polish admin shell truoc vi anh huong toan app.
4. Polish Dashboard va Orders vi day la hai man admin quan trong nhat.
5. Polish Customer QR mobile flow.
6. Ra soat Branches/Tables/Menus de dong bo visual pattern.
7. Kiem tra responsive desktop/mobile cho cac man da cham.
8. Chay lint/typecheck/build neu script san sang.

## Ngoai Scope

- Khong doi API contract.
- Khong doi database/schema/backend service.
- Khong them Redux hoac state library moi chi de polish UI.
- Khong them feature nghiep vu moi nhu category, inventory, printable bill, reservation.
- Khong lam production deploy/release checklist cua Step 11.
- Khong refactor lon realtime/data fetching neu da nam trong Step 10.1 va khong can cho polish.

## Test / Smoke Test

- Admin login va dieu huong cac man khong vo layout.
- Dashboard hien metric/filter/top menu/status summary tren desktop va mobile.
- Orders:
  - Load branch/order list.
  - Chon order thay detail.
  - Update status van chay.
  - Confirm payment modal van chay.
  - Realtime pill/toast khong che UI bat hop ly.
- Branches/Tables/Menus:
  - Create/edit basic flow van chay.
  - Empty/loading/error state hien dung.
- Customer QR:
  - Mo QR route tren mobile width.
  - Tang/giam so luong.
  - Submit order.
  - Xem tracking status.
- Doi theme/language khong lam layout vo.
- Chay `npm run lint`, `npm run typecheck`, `npm run build` neu moi truong cho phep.

## Hoan Thanh Khi

- UI admin va customer QR co visual hierarchy ro, dep hon, va dong bo component.
- Cac flow nghiep vu da co van chay nhu truoc.
- Mobile khong overlap text/button, khong co horizontal scroll bat thuong.
- Mau sac/trang thai/action dung token hoac helper chung, khong hard-code tuy tien.
- Co smoke test note de user review truoc khi chuyen Step 11.
